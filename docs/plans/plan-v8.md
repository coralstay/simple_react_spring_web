# plan-v8 — leaf task 구현 전 상위 2뎁스(부모 task+마일스톤) 필수 확인

이전 버전: plan-v1~v7.md (모두 변경하지 않음)

## 변경 사항(불변식에 추가)

leaf task를 구현하는 서브에이전트는 자신의 leaf task뿐 아니라 **상위 2단계**를 반드시 먼저
확인하고 그 맥락을 코드에 반영해야 한다:
1. **부모 task**(`backlog task view <parent>`) — 이 leaf가 속한 기능 전체의 의도, 다른 형제
   leaf와의 관계
2. **마일스톤**(`backlog milestone list`로 소속 마일스톤 확인) — 이 작업이 전체 계획에서
   어느 단계에 해당하는지

이렇게 해야 leaf 하나만 보고 좁게 판단해서 상위 AC/의도와 충돌하는 구현을 하는 문제(예:
TASK-3.1에서 AC 문구와 실제 지시가 어긋났던 사례)를 미리 줄일 수 있다. 모든 향후 서브에이전트
프롬프트에 이 "상위 2뎁스 확인" 지시를 포함한다.

## 영향받는 범위
- 서브에이전트에게 leaf task를 위임할 때 프롬프트에 "부모 task + 마일스톤 확인" 단계를 항상 포함
