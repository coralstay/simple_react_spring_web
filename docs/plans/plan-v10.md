# plan-v10 — 마일스톤 전환: 직전 리뷰가 이미 통과했으면 자동 진행

이전 버전: plan-v1~v9.md (모두 변경하지 않음)

## 변경 사항(plan-v3/v5 규칙 정교화 — 완전 생략 아님)

plan-v3(reviewer 리뷰 게이트)/plan-v5(verify 검증 게이트)는 여전히 유효하다. 다만 자동 크론이
매번 사람 개입을 기다리며 멈추는 것은 비효율적이라, 다음과 같이 정교화한다:

- **직전 마일스톤이 이미 reviewer+verify 양쪽 모두 "통과(PASS)"로 기록되어 있다면**, 크론은
  다음 마일스톤의 task를 자동으로 계속 진행한다.
- **아직 리뷰/검증이 진행 중이거나 FAIL/보류 상태라면**(M1처럼 verify가 FAIL을 낸 뒤 수정 중인
  경우), 크론은 현재 마일스톤 안의 남은 task만 처리하고 다음 마일스톤으로는 넘어가지 않는다.
- 판단 근거: 해당 마일스톤의 모든 task에 연결된 backlog doc(reviewer/verify가 남긴 문서)의
  최종 결론이 PASS인지를 확인한다. 애매하면 진행하지 않는 쪽(보수적 판단)을 택한다.

## 영향받는 범위
- 클라우드 크론(schedule 루틴) 프롬프트에 이 판단 로직 반영 필요
- "실행 방식"/plan-v3/v5 게이트 로직의 구체적 판정 기준으로 이 문서를 참조
