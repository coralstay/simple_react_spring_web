# plan-v15 — 기술 이야기 시 항상 "어디에 있는 무엇"인지 명시

이전 버전: plan-v1~v14.md (모두 변경하지 않음)

## 규칙

크론, 훅, 서버, 프로세스 등 기술적인 것을 언급할 때는 항상 **정확히 어디에 위치한
무엇인지**를 함께 말한다(예: "OS의 crontab인지, Claude Code의 클라우드 스케줄
routine인지", "로컬 .git/hooks인지, 전역 ~/.claude/hooks인지"). 애매하게 "크론이",
"훅이"라고만 부르지 않는다.
