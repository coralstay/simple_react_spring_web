# plan-v6 — 머지 정책 확정 + 커밋당 토큰 기록 규칙

이전 버전: plan-v1~v5.md (모두 변경하지 않음)

## 변경 사항(불변식에 추가)

### 1. 머지 정책
- **main 브랜치 머지는 사용자가 직접 검토 후 수행한다.** Claude는 main에 강제로 push하지 않는다
  (하네스 auto-mode 분류기가 관련 안전 훅 수정 자체를 차단해 확인된 제약이기도 하다).
- Claude는 각 task 브랜치를 항상 최신 main 위에 **rebase된 상태**로 유지해 사용자가 fast-forward로
  깔끔하게 머지할 수 있게 한다.
- **스쿼시 머지는 하지 않는다** — task 브랜치의 함수/파일 단위 커밋 이력을 그대로 보존한다
  (fast-forward 또는 일반 병합만 사용, --squash 금지).

### 2. 커밋당 토큰 사용량 기록
모든 커밋은 그 작업에 사용된 토큰 사용량을 기록으로 남긴다. 다만 **개별 커밋 시점에 실시간
토큰 소비량을 도구가 노출하지 않는다는 기술적 제약**이 있어, 다음과 같이 근사한다:
- 서브에이전트가 leaf task 하나(또는 task 전체)를 마칠 때, 오케스트레이터가 받는 완료 보고서의
  `usage.subagent_tokens`/`tool_uses` 값을 그 task의 **마지막(Done 처리) 커밋** 메시지에
  `Tokens-Used: <N>`, `Tool-Calls: <N>` 트레일러로 남긴다.
- 정확한 커밋 단위 실시간 값이 아니라 **task 단위 총합의 근사치**라는 점을 명시한다 — 이후 더
  세밀한 방법(예: 커밋마다 직접 확인 가능한 도구)이 생기면 이 규칙을 갱신한다.

## 영향받는 범위
- "실행 방식" 섹션에 위 두 규칙 추가
- 앞으로 모든 task Done 처리 커밋에 Tokens-Used/Tool-Calls 트레일러 포함
